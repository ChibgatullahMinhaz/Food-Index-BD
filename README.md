# Food Index BD

Food Index BD is an online grocery storefront focused on natural and organic
food products for customers in Bangladesh. Customers can explore products,
choose available weight options, add items to a cart, and place orders through a
streamlined checkout experience.

## Features

- Browse products by category and search the catalog.
- View product details, images, prices, stock, and available weight options.
- Add products to a shopping cart and manage quantities.
- Place orders with customer, delivery, and payment details.
- Choose a delivery area and view the associated delivery charge.
- Manage products and orders through an admin dashboard.
- Review store statistics, inventory, and order statuses.
- Generate printable order invoices.

## Technology

- **Next.js** with the App Router and API route handlers
- **React** and **TypeScript**
- **Tailwind CSS** for styling
- **PostgreSQL** with **Prisma** for data access
- **shadcn/ui** components and **Lucide** icons

## Project Structure

- `src/app/` — Application pages and API routes
- `src/components/` — Storefront and admin interface components
- `src/lib/` — Shared utilities and database access
- `src/services/` — Product, category, and order business logic
- `src/types.ts` — Shared application types
